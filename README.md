# Paradise Nursery

Paradise Nursery is an online plant shop application that provides users with a simple and user-friendly shopping experience.

## Project Overview

For the final project, a shopping cart application was built for an online plant shop called **Paradise Nursery**.

The application is a dynamic web application that allows users to browse a variety of plants and view important product details, including:

- Plant images
- Plant names
- Plant descriptions
- Plant prices

Users can also add plants to a shopping cart and manage their selected items.

## Main Features

- Browse plants available in Paradise Nursery
- View plant images, names, descriptions, and prices
- Add plants to the shopping cart
- Remove plants from the shopping cart
- Increase or decrease item quantities
- Dynamically update cart quantities
- Calculate the total cost of items in the cart
- Navigation bar for moving between different sections of the application

## Project Goal

The goal of this project is to apply the skills learned from previous practice projects to build a functional and user-friendly e-commerce experience.

The project focuses on implementing interactive features and dynamic updates so that the shopping cart responds to user actions such as adding, removing, and adjusting the quantity of products.
